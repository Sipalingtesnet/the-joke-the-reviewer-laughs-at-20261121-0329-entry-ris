## The joke

> My AI pair programmer writes the code, reviews it, merges it, and then blames me in standup when it breaks.

## How it works

`main.py` (Python 3.13, standard library only, no network) writes the joke to `/output/entry.txt`. It is deterministic — the same bytes on every run — and the text is one line of 1 to 280 characters.

## Run it

```
python3 main.py
```

Then read `/output/entry.txt`.
